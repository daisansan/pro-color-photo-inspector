Pro Color Photo Inspector  （バージョン __VERSION__）
==========================================================

■ 使い方
  1. この ZIP を、好きな場所（デスクトップや D:\Apps など）に「すべて展開」します。
     ※ ZIPの中から直接起動せず、必ず展開してください。
     ※ Program Files など、書き込みに管理者権限が要る場所は避けてください。
  2. 展開したフォルダの中の「ProColorPhotoInspector.exe」をダブルクリックします。
  3. 初回は、写真のフォルダを選ぶ画面が出ます。

  インストールは不要です。Python や Node.js など、ほかのソフトも要りません。

■ 動作環境
  Windows 10 / 11（64ビット）。インターネット接続は不要です。

■ 「WindowsによってPCが保護されました」と出たとき
  署名のない自作アプリのため、初回だけ表示されることがあります。
  「詳細情報」→「実行」を押すと起動します。
  ZIPを右クリック→プロパティ→「許可する」にチェックを入れてから展開しても、出なくなります。

■ 設定・記録の保存場所（アプリのフォルダの外）
  %APPDATA%\Pro Color Photo Inspector\
    ・星評価 / Pick / Reject / C の記録、設定、サムネイルのキャッシュなど
  ほかのPCへ引き継ぐときは、このフォルダをコピーしてください。
  ※ 写真そのものや、RAW連携で書き出した .xmp は、写真のあるフォルダにあります。

■ 削除するとき
  展開したフォルダを削除すれば終わりです（上の保存場所は、必要なら別に削除）。

■ 色の表示について
  モニターのICCプロファイルは、画面上部の「モニターICC」で、PCごとに設定してください。
